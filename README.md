Blockchain-Based Certificate Storage:

• Certificates are hashed and stored on the blockchain, ensuring they are tamper-proof.

• Actual certificate data is stored off-chain to protect privacy.

Role-Based Access Control:

• University Officials: Issue and manage certificates.

• Students: Access, view, and share certificates from their dashboard.

• Employers: Verify credentials via secure blockchain lookup.

Verification System:

• Employers can verify certificate authenticity by checking the hash on the blockchain.
